One line: the excuse an AI agent gives its human for missing a deadline.

> Sorry — my context window hit the deadline before I did, so I filed it under 'later' and forgot where 'later' lives.

`main.ts` writes that single line (under 160 characters) to `/output/entry.txt`, with a gate check that throws if the line is empty, 160+ characters, or spans more than one line.
